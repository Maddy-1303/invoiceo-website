Recommended for you

Windows

Windows 10 and 11 · 64-bit

Download for Windows

Invoiceo-Setup-Windows.exe

  1. Open the downloaded file.
  2. If Windows shows “Windows protected your PC”, click More info, then Run anyway. This appears because the installer is not code-signed yet.
  3. Follow the setup. Invoiceo then opens from the Start menu.
Recommended for you

macOS

macOS 12 Monterey or later

Download for macOS

Invoiceo-macOS.dmg

  1. Open the .dmg and drag Invoiceo into Applications.
  2. Open Invoiceo. If macOS says it cannot verify the app, click Done. This happens because the app is not notarised by Apple yet.
  3. Open System Settings → Privacy & Security, scroll down to the message about Invoiceo and click Open Anyway, then confirm. (On macOS 14 or older you can instead Control-click Invoiceo in Applications and choose Open.)
  4. After that it opens normally.
Recommended for you

Linux

Ubuntu 22.04+, Debian 12+, Mint 21+ and others

Download .debDownload AppImage

Invoiceo-Linux.deb
Invoiceo-Linux.AppImage

  1. .deb (Ubuntu 22.04+, Debian 12+, Linux Mint 21+): run sudo apt install ./Invoiceo-Linux.deb in the folder you downloaded it to.
  2. AppImage (other distributions): run chmod +x Invoiceo-Linux.AppImage, then open the file.

Check your download with the SHA-256 checksums
