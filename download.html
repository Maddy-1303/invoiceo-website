Download

Windows

Windows 10 or 11, 64-bit · .exe installer

Download for Windows
  1. Open the downloaded file.
  2. If Windows shows “Windows protected your PC”, click More info, then Run anyway. This appears because the installer is not code-signed yet.
  3. Follow the setup. Invoiceo then opens from the Start menu.

macOS

macOS 12 Monterey or later · .dmg disk image

Download for macOS
  1. Open the .dmg and drag Invoiceo into Applications.
  2. Open Invoiceo. If macOS says it cannot verify the app, click Done. This happens because the app is not notarised by Apple yet.
  3. Open System Settings → Privacy & Security, scroll down to the message about Invoiceo and click Open Anyway, then confirm. (On macOS 14 or older you can instead Control-click Invoiceo in Applications and choose Open.)
  4. After that it opens normally.

Linux

.deb for Ubuntu 22.04+, Debian 12+ and Linux Mint 21+ · AppImage for other distributions

Download .deb Download AppImage
  1. .deb: run sudo apt install ./Invoiceo-Linux.deb in the folder you downloaded it to.
  2. AppImage: run chmod +x Invoiceo-Linux.AppImage, then open the file.
Invoiceo is free. You never need to pay to download it, install it on more computers or keep using it.

Updating to a new version

Download the new installer and install it over the old version. Your data is kept, but we recommend making a backup first from Settings → Backup in the app.
